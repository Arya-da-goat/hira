# Kira

Kira is a ChatGPT-inspired chatspace built as a lightweight Node.js web app.

## Features

- Dark-mode chat interface
- Sidebar navigation
- Message composer
- AI-style response generation from a local backend
- Responsive layout for desktop and mobile

## Run locally

```bash
npm install
npm start
```

Then open http://localhost:3000 in your browser.

## Project structure

- `server.js` — Node.js server and local chat API
- `public/index.html` — app shell
- `public/styles.css` — UI styling
- `public/app.js` — chat behavior

## Notes

This is a front-end demo with a local conversational backend so the interface feels like a real chatspace without needing external AI APIs.
